
# Customer Churn Analysis Dashboard

This Excel dashboard provides an overview of customer churn, revenue impact, customer behavior, and support activity.

## Dashboard Highlights

- Total customers and cancelled customers
- Customer churn rate
- Monthly recurring revenue (MRR)
- MRR associated with active and cancelled customers
- Cancellation by plan type
- Churn distribution
- Average support tickets
- Average usage hours
- Key insights and recommendations

## Tools Used

- Microsoft Excel
- Excel PivotTables
- Excel Charts
- Data Analysis
